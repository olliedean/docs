Ars Nouveau adds custom spells, magical crafting, Source-powered machines, and automation. This page covers the starting points and links to more detailed help.

## Getting started

1. Craft the Worn Notebook for the in-game guide.
2. Craft a Novice's Spell Book.
3. Use a Scribe's Table to unlock more glyphs.
4. Build an Imbuement Chamber to produce Source Gems.
5. Set up Source generation and an Enchanting Apparatus for advanced crafting.

Use JEI for recipes in Brass, Bloom & Beyond.

- [Spellcasting basics](https://ars.guide/book/getting_started/spell_casting/)
- [Scribe's Table and unlocking glyphs](https://ars.guide/book/crafting/scribes_table/)
- [Browse the in-game guide online](https://ars.guide/book/)

## Making spells

Select the Spell Book and press `C` to open the spell editor. Spells combine a casting form, effects, and optional augments.

```text
Touch → Break              Mine a targeted block
Projectile → Harm          Ranged damage
Self → Heal                Heal the caster
Projectile → Conjure Magelight   Place a light at the impact point
```

Some glyphs require a higher-tier Spell Book. Add augments after the effect they modify, and check the editor for compatibility and mana cost.

- [Using the spell editor](https://ars.guide/book/getting_started/introduction_to_spellcrafting/)
- [Glyph reference for Minecraft 1.21.1](https://ars.guide/1.21.1/docs/spell_theory/glyphs/)
- [Tier One glyphs](https://ars.guide/book/glyphs_tier_one/)

The external glyph reference also includes addon content; check which mod provides each glyph.

## Mana and Source

- Mana powers player-cast spells and regenerates over time.
- Source powers crafting and automation. Sourcelinks generate it; Source Jars store it.

A full Source Jar does not directly refill personal mana.

An Agronomic Sourcelink generates Source from crop and tree growth. A Volcanic Sourcelink consumes burnable materials.

- [Agronomic Sourcelink guide](https://github.com/Jarva/Ars.Guide/blob/main/src/content/docs/sourcelinks/agronomic.mdx)
- [Volcanic Sourcelink guide](https://ars.guide/book/source/volcanic_sourcelink/)
- [Sourceberries and mana regeneration](https://ars.guide/book/field_guide/sourceberry_bush/)

## Magical crafting

| Block | Purpose |
|---|---|
| Imbuement Chamber | Produces Source Gems, essences, and other infused materials |
| Enchanting Apparatus | Crafts advanced equipment and components using surrounding pedestals |

Place an Arcane Core directly beneath the Enchanting Apparatus.

Imbuement Chamber pedestal items are reusable. Enchanting Apparatus pedestal ingredients are consumed.

- [Imbuement Chamber setup](https://ars.guide/book/crafting/imbuement_chamber/)
- [Enchanting Apparatus setup](https://ars.guide/book/crafting/enchanting_apparatus/)

## Equipment and automation

Mage armor, Threads, and accessories improve spellcasting. Magical creatures provide automation, including Starbuncles for item handling and Drygmys for eligible mob resources.

Use the Worn Notebook for individual creature, ritual, and equipment instructions.
